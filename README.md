# 听页

Windows 本地 EPUB 小说朗读器。双击 **发布/程序/对白自适应版/听页/听页.exe**，也可以把 EPUB 文件拖到 EXE 上。

## 安装与更新

首次使用时，将 **程序** 和 **模型库** 放在同一个目录下：

```text
发布/
├─ 程序/对白自适应版/听页/
│  ├─ 听页.exe
│  └─ _internal/
└─ 模型库/
   ├─ zipvoice-distill-fp32-v1/
   └─ wetts-baker-bert-v1/（final.onnx 和 vocab.txt）
```

以后只需把新版的整个程序文件夹放到“程序”下。模型库可供多个版本共用。换电脑时复制需要的程序版本和一份模型库，保留上述相对位置即可。模型也可以放在其他磁盘。程序在约定位置找不到完整模型时，会提示选择模型库或其中的 **zipvoice-distill-fp32-v1** 文件夹，选择成功后会记住位置。

## 使用

首次启动使用浅色主题。点「语音调节」左侧的 **切换深色** 或 **切换浅色** 即可更换界面配色，下次启动会沿用你的选择。

点 **语音调节… → 朗读服务 → Mac mini · CosyVoice 3**，可以在右侧选择龙修、龙逸尘、龙飞、龙白芷、龙安温或龙妙。首次选择 Mac 时使用龙修。点 **试听当前设置** 可以试听，点 **保存并关闭** 会记住服务和音色。打开 EPUB 后，点 **从此处朗读** 开始，底部的 **上一段、下一段、暂停、停止** 控制播放。

Mac 模式将分好的原文经家庭局域网发送到 `192.168.3.125:9880`。每次请求返回一段完整的 WAV，听页按剩余可播秒数提前请求后续段落。服务连接失败时，窗口会显示错误，恢复连接后可再次点朗读或试听。下文的合成步数、WeTTS 等参数用于本机 ZipVoice。

1. 点 **打开 EPUB** 或按 Ctrl+O，选择文字型 EPUB 2 或 EPUB 3。右侧的 **最近打开文件** 列出最近成功打开的 10 个文件，点选即可重新打开。若文件已移动或删除，提示框会显示原路径。
2. 单击正文中的一个字，再点底部 **从此处朗读** 或按 Ctrl+Enter，会从该字所在句子的句首开读。拖选文字后，起读位置取选区开头所在句子的句首。右键菜单的 **从此处朗读** 采用同样的规则，右击选区之外时以右击的字为准。每次主动起读都会恢复自动翻页。
3. **暂停 / 继续** 或空格控制播放。选中其他位置并重新开读，会立即丢弃旧位置的待播音频。浏览目录时，原位置的播放可以继续。
4. 播放按 EPUB 的阅读顺序自动进入下一章，直至书末。再次打开同一文件时会定位到上次播到的片段。书签存放在当前 Windows 用户的 LocalAppData/TingYe 中。
5. 在 **语音调节 → 合成步数** 中选择 **4 步** 或 **8 步**。默认使用 4 步。点 **保存并关闭** 后，正在朗读的片段会从开头按新设置重新合成，下次启动也会沿用所选步数。
6. 高亮片段完整可见时，页面保持原位。片段超出可视区域时，会把它的首行移到正文顶部。使用正文滚轮、滚动条或翻页键可临时自由浏览；点 **跳转到朗读位置** 可返回当前正在听的片段，并恢复自动翻页。暂停时也可以跳转。

点 **语音调节…** 可查看当前生效的参数，调整步数、语速、模型引导强度和高频柔化。每项旁边都有说明。输入书里的一句话，点 **试听当前设置** 即可比较听感。**恢复默认** 会把面板调回 4 步、1.00 倍速、引导强度 3.00、柔化 0%。点 **保存并关闭** 才会把面板的数值用于正文，并在下次启动时载入。若在听书时试听，关闭面板后会从原朗读片段开头恢复，原来暂停的会继续暂停。

主界面底部的 **音量** 滑条同时控制正文和试听。拖动或点击滑轨可立即改变音量，0% 为静音，重新打开时沿用上次的音量。

## 本地运行

**语音调节 → WeTTS 自动断句（本地）** 默认开启，正文和试听共用。WeTTS 预测中文韵律，将中等及以上的段内边界转换为合成用逗号。遇到特别长且缺少标点的句子时，开启 WeTTS 可优先在预测的韵律边界切分。高亮和书签仍按原文定位。想比较同一句的效果，可以切换此选项并点击试听，保存后用于正文。WeTTS 在第一次使用中文自动断句时加载，此后由同一语音进程复用。如自定义模型位置，请将两个模型包放在同一父目录下。

界面使用 Python 自带的 Tk。独立进程预加载 ZipVoice-Distill 的 FP32 编码器、解码器和 Vocos 声码器，在 CPU 上合成。两种朗读服务都把 30～60 个朗读字符作为参考。短对白可以单独读，带有说话人提示的完整对白可适当超过 60 字。遇到特别长的台词，优先在这位人物的句号、问号等停顿处拆开。正文按自然段和章节分开处理，高亮和跳读使用原书位置。首段优先选择较短的自然停顿，后续根据剩余可播秒数和最近几段的实测合成速度调整目标长度。开头很短时，听页会稍作预缓冲。正文按需读取，最多保留四个正文文件。

运行源码时可以双击 **启动听页.cmd**。重新搭建环境时使用带 Tk 的 Windows x64 Python 创建 .venv，按 requirements.txt 安装依赖。源码优先读取上述共享目录，也兼容原有的项目 models 目录。安装 PyInstaller 后，用 PowerShell 7 执行 build.ps1 即可打包程序。发布其他版本可指定新的目录，例如 `./build.ps1 -DistPath '发布/程序/下一版'`。以下路径均相对于模型包根目录：

- zipvoice-distill-fp32/ 中的 text_encoder.onnx、fm_decoder.onnx、lexicon.txt 和 tokens.txt
- vocos_24khz.onnx 和 lexicon-en-us.txt
- reader-reference-distill-zh.wav，官网跨语言试听第一行最右侧中文音频中 3.47 至 7.60 秒的片段，与推理配置中的中文逐字稿配套

模型与运行环境齐备后，首次启动、打开小说和语音合成均可断网运行。当前版本面向无 DRM、正文为文字的 EPUB，图片文字识别不在此版本范围内。
